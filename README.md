# わくわく パズル（第一段階）

幼児向けの、ブラウザーだけで動くジグソーパズル試作版です。GitHub Pages で公開できます。

## 使い方
1. `index.html`、`styles.css`、`js/app.js` を同じフォルダー構成で保存します。
2. GitHub リポジトリにアップロードします。
3. GitHub の **Settings → Pages** で公開元ブランチとフォルダーを指定します。
4. 公開 URL を Android の Chrome で開きます。
5. 「画像をえらぶ」で端末内の画像を選び、「パズルをはじめる！」を押します。

## 第一段階に含まれるもの
- 端末内の画像を使ったパズル（画像をサーバーにアップロードしません）
- 4 / 9 / 16 ピース
- 凸凹のあるジグソー形状
- タップ選択・ドラッグ操作
- 正しい場所に置くと固定
- 回転設定（90 度単位）
- 最初の正解までは薄い完成図ガイドを表示
- 正解音とクリア画面
- ピース数・回転設定のみ `localStorage` に保存

## 試作版の注意
- まず操作感を確認するための第一段階です。タブレットやスマートフォンの画面サイズによっては、16 ピースのトレイが小さく感じられる場合があります。
- 回転ありの場合、正しい向き（0 度）に戻してから正しい場所に置く仕様です。
- ブラウザーや端末によって画像読み込み・音声の挙動が異なることがあります。
- 画像はページを閉じると保持されません。設定以外の情報は保存しません。
